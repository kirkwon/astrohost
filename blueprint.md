# Project Blueprint

## Overview

This project is a modern, content-focused website built with Astro.js. It features a blog about the history of AI, a clean, modern design with light and dark modes, and a responsive layout.

## Design and Features

*   **Framework:** Astro.js
*   **Styling:** Tailwind CSS with a custom color palette and typography.
*   **Theme:** Light and dark mode with a theme toggle in the header.
*   **Layout:** Responsive design with a header, main content area, and footer.
*   **Pages:**
    *   **Home:** Displays a timeline of AI history and a grid of blog posts.
    *   **Blog Post:** Displays the content of a single blog post with a featured image and publication date.
*   **Components:**
    *   **Header:** Contains the site logo and theme toggle.
    *   **Footer:** Contains copyright information and social media links.
    *   **Card:** Displays a preview of a blog post with a featured image, title, and description.
    *   **Logo:** The site logo.
    *   **ThemeToggle:** A button to switch between light and dark mode.
